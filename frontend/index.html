What DeepTruth does, which models it uses, and where it stops being reliable.

HACKATHON PROJECT

How it works

  1. Validate. The server checks the file type, size and real file signature, and hashes the upload (SHA-256) so a report can identify exactly which file was examined.
  2. Analyse. Images go to a pretrained classifier. Videos are split into evenly spaced frames, and each frame goes to the same classifier.
  3. Explain. For images, Grad-CAM shows which patches pushed the score up. A face check tells you whether the image is the kind this model was trained on.
  4. Report. The score, evidence, warnings and limitations are written to a PDF. The uploaded file is deleted as soon as analysis ends.

Models and methods

Image and video frames
DeiTFake v2: a DeiT vision transformer for fake-vs-real facial images, trained on OpenForensics-derived data. Apache-2.0 per its model card.
Face check
OpenCV Haar cascade for frontal faces. A coarse scope check, not a forensic step.
Explainability
Grad-CAM over the final transformer block’s patch tokens, taken for the model’s fake class.
Audio
No detector is installed. The server exposes an adapter interface for a reviewed model.

Reading a score

The score is the checkpoint’s own output for its “fake” class, on a 0–100% scale. It is not a calibrated probability, and it is not the chance that a file is fake.

The low / inconclusive / elevated bands are presentation choices for readability. They have not been validated as decision thresholds. A high score means “review this more closely”, and a low score does not prove authenticity.

What it can help with

  • Screening face images for patterns the model learned from its training data
  • Showing which regions drove a score (explanation of the model, not of the edit)
  • Spotting individual video frames that deserve a human look
  • Producing a documented, hash-identified record of what was run

What it cannot do

  • Prove that any media is real or fake
  • Reliably judge images without faces, or manipulation types missing from the training data
  • Detect temporal artefacts in video such as lip-sync or motion inconsistencies
  • Locate edited pixels. Grad-CAM is not a tamper map
  • Analyse audio, which is unsupported for now

Audio: what a suitable detector needs

Before a synthetic-speech model is enabled it should have a documented, redistributable licence, evaluation on data that resembles your recordings (compression, languages, noise), and a loading path that does not execute untrusted code. Several public checkpoints exist, but many are small community projects with custom architectures or restrictive licences, so DeepTruth leaves audio disabled instead of presenting an unverified score.

Ethical use

DeepTruth supports careful human review. Do not use a score as the sole basis for accusing, sanctioning or publicly identifying anyone. Automated detectors produce false positives and false negatives. Only analyse media you have a right to examine, respect the privacy and consent of the people shown, and corroborate findings with source verification and expert review.
